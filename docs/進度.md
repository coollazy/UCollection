- **開發語言：Go**（三項可行性驗證用 Go 重做全部一次通過，image 最小、純靜態連結、無相容性問題；相較 Swift 踩了兩個 Linux 相容性坑、image 378MB）
- **資料庫：PostgreSQL**（比較 PostgreSQL／MySQL／SQLite 後定案，關鍵考量：地址分配的併發安全用 advisory lock 處理最直觀、JSONB 適合審計日誌明細、長期報表擴充性夠）
- **前端：Go `html/template` + htmx**（零 Node.js 建置鏈，僅高風險頁面單獨 vendor 對應函式庫離線打包）
- **不內建反向代理/自動 HTTPS**（假設商戶自行架設 nginx/Cloudflare 等前方 TLS 終止；系統只需監聽一般 HTTP port；未來要加不難，之後在 docker-compose 多掛一個 container 擋在前面即可，不需改動現有程式碼）
